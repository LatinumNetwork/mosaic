# Graph Tooltip

The `GraphTooltip` component provides an informative tooltip for graphs. It displays rows of data with labels and values, supports optional unit measurements, and can be positioned flexibly.

## Usage

The `GraphTooltip` component accepts the following props:

- **rows:** An array of objects containing `label` and `value` properties to display.
- **unitMeasurement:** An optional string appended to each value.
- **top, left, right:** Positioning properties to place the tooltip.
- **arrowPosition:** Position of the tooltip's arrow (`top`, `bottom`, `left`, or `right`).
- **xPosition, yPosition:** Alignment options for more refined positioning.
- **open:** A boolean to control whether the tooltip is visible.
